A /explainer skill that turns a meeting, a paper or a folder into an explainer, in a style you've trained.

INTENT, NOT SHIPPED · decisions recorded 2026-10-01 · ready for to-spec
01 // WHAT IT IS

Any source in, four outputs out

Point /explainer at anything the agent can reach; a local web app runs the loop and produces one of four outputs.

02 // WHY STYLES

Quality is a style problem

bars show the source's qualitative judgement, not measured data

That's why styles are first-class, iterated assets, not a prompt line.

03 // THE STYLE LOOP

How a style gets good

Describe
"Hitchhiker's Guide, neon blue/green, lively…" (name it now or later)
Pick voice
TTS provider · character · speed
Render ~10 s sample
opening · transition · pop-up · box · diagram · camera
exercises everything
Comment
"voice is wrong"
"contrast too low"
Re-render
swap voice or model from a dropdown
Save
named, versioned, cloneable

Describe, pick a voice, render a 10-second sample, comment, re-render, save; each round refines the style prompt.
